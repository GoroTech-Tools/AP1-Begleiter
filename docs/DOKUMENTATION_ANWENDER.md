# Dokumentation Anwender

## Zweck

`AP1-Begleiter-Portable` öffnet zwei Browserfenster (links/rechts), damit Anleitungen und Intranet parallel genutzt werden können.

## Start

1. `AP1-Begleiter-Portable.exe` starten.
2. Auf **Starten** klicken.
3. Optional: Checkbox **Fenster automatisch links/rechts anordnen** aktiv lassen.

## Funktionen

- Öffnet zwei URLs aus dem Standardprofil.
- Ordnet die Fenster auf dem Hauptbildschirm an.
- Öffnet die Kurzdokumentation über den Button **Dokumentation**.

## Hinweise

- Wenn Microsoft Edge nicht gefunden wird, werden Links im Standardbrowser geöffnet.
- Einstellungen werden unter `%APPDATA%\AP1-Begleiter-Portable` gespeichert.
